# T05: новые таргеты для канонических нот, 6 октября 2026

Сохранён пригодный для загрузки набор дополнительных таргетов, размеченных
Astra с запрошенными `gpt-6-astra` / `ultra`. Это 18 положительных флагов для
16 конкретных нот в трёх произведениях текущего TRAIN. Флаги имеют доступные
маски. Реальная загрузка через существующий collator проверена: положительные
значения кодируются как `1`, неизвестные — как `-1` с выключенной маской.

[Индекс выпуска](../../outputs/tonal_relations_targets_20261006_001/release/index.json)
содержит пути и SHA-256 канонических произведений, TargetBundle и точных
назначений. [Спецификация](../workstreams/2026-10-06/relational-midi-targets/spec.md)
была сохранена до запуска;
эксперимент — `EXP-TONAL-RELATIONS-TARGETS-001`.

| Произведение | Нот в каноническом файле | Нот с новыми флагами | Флагов |
|---|---:|---:|---:|
| Mozart K283-I | 3308 | 3 | 3 |
| Mendelssohn Op12-I | 3639 | 10 | 11 |

Размечены выбранные эпизоды. Наличие всех нот произведения в TargetBundle
не означает полной разметки: 78 444 из 78 462 пар «нота × тип флага» остаются
неизвестными. Контекстные ноты не получают флаг автоматически.

| Таргет после префикса `theory.relations.` | Значение | Доступных меток |
|---|---|---:|
| `held_common_tone` | Удерживаемый общий тон | 2 |
| `resolving_chordal_seventh` | Септима, участвующая в разрешении | 3 |
| `resolution_arrival` | Нота, в которую происходит разрешение | 3 |
| `anticipation` | Предвосхищение следующей гармонии | 1 |
| `anticipated_arrival` | Последующее появление предвосхищённого тона | 1 |
| `contrary_ascending` | Восходящая сторона противодвижения | 3 |
| `contrary_descending` | Нисходящая сторона противодвижения | 3 |
| `octave_upper` | Верхний участник октавного удвоения | 1 |
| `octave_lower` | Нижний участник октавного удвоения | 1 |

У каждого назначения есть существующий `note_id`, точный интервал в четвертях,
`relation_id`, связанные канонические ноты и исходные события. Например, нота
`note:dilemmadata-308928919c5ba03b80ddc2ab-00000005` у Мендельсона получила
`resolution_arrival` и `anticipation`; её C5 одновременно завершает предыдущее
движение и предвосхищает следующую гармонию. См.
[точные назначения](../../outputs/tonal_relations_targets_20261006_001/release/mendelssohn-op12-i/event-assignments.json).
Это интерпретация Astra с опорой на ноты и исходную гармоническую разметку,
а не независимая экспертная оценка.

## Загрузка

Из корня репозитория, в окружении проекта с `PYTHONPATH=src`:

```python
import json
from pathlib import Path
from music_critic.data import load_piece
from music_critic.tasks import (
    loads_target_bundle, prepare_multisource_sample,
    attach_target_bundle, collate_multisource_samples,
)

root = Path("outputs/tonal_relations_targets_20261006_001/release")
entry = json.loads((root / "index.json").read_text())["works"][1]
piece = load_piece(entry["canonical_piece"]["path"])
targets = loads_target_bundle(Path(entry["target_bundle"]["path"]).read_text())
sample = attach_target_bundle(prepare_multisource_sample(piece), targets)
batch = collate_multisource_samples((sample,))
roles = [t for t in batch.target_batches if t.task_id.startswith("theory.relations.")]
assert sum(int(t.availability_mask.sum()) for t in roles) == 11
```

При запуске выпуска из новых аннотаций используйте
`scripts/build_relational_midi_targets.py <input-manifest.json> <new-output-directory>`.
Уже существующий каталог выпуска не перезаписывается. Экспорт проверяет хеши
входов; приведённый краткий пример чтения предполагает сохранность готового
выпуска. Полная проверка байтов и загрузчика сохранена в
[loader-verification.json](../../outputs/tonal_relations_targets_20261006_001/loader-verification.json).

## Проверки и ограничения

Все 166 исходных нотных сегментов точно связаны со 165 каноническими нотами.
Два сегмента связанной ноты Мендельсона относятся к одному событию. Mozart
использует сохранённое в исходном преобразовании смещение `+2/1` четверти.
Первая попытка с нулевым смещением корректно остановилась; её ошибка сохранена.
Первая попытка экспорта также остановилась из-за отсутствующего `split` в старом
каноническом архиве. В повторной попытке проверенный текущий TRAIN используется
только во временном представлении для построения таргетов; исходные байты
произведений не изменяются. Встроенный heldout split по-прежнему запрещён.

Самопроверка семантических назначений: 594/594. Независимая проверка выпуска
сверила все 78 462 пары нота×флаг и 18 назначений с исходными ролями. Реальная
CPU-проверка загрузки подтвердила 18 доступных меток и неизменность raw graph
у всех трёх произведений. Эти проверки устанавливают корректность переноса
и загрузки, но не музыкальную accuracy Astra.

Standards и Spec review завершены без замечаний. Набор из 193 unit/regression
тестов на фикстурах дал 192 passed и один отказ sandbox на запуск `torch_shm_manager`.
Единственный заблокированный тест сравнения загрузчиков с 0/2 workers
повторён вне sandbox: 1 passed. Существующее предупреждение Torch остаётся.
Проверены новые binder/targets/exporter и существующие multisource contracts,
collator и dataset. Отдельная дополнительная adapter/cache-проверка не собрана
из-за отсутствующего optional `hydra`; эту зависимость не устанавливали.

Метки имеют `source=pseudo_label`, `confidence=null`, режим
`positive_unlabeled`. Без проверенных отрицательных примеров обычная бинарная
классификация может выучить постоянный положительный ответ; стратегия обучения
и независимая проверка семантики ещё нужны. Новые нейронные головы и обучение
в этот выпуск не входят. Существующие core ontology/encoding fingerprints
сохранены. Legacy не читался и не переиспользовался; зависимости не добавлялись.

Девять внешних рок/поп/джаз-версий из T04 не включены: для них пока нет
проверенной связи с текущими каноническими TRAIN-событиями. Перечень причин
сохранён в индексе. Следующий этап — такие привязки и расширение покрытия
меток; полный TRAIN пока не размечен. Семь типизированных отношений и 29
пересечений нота×гармония сохранены в исходном пакете Astra как дополнительное
структурированное свидетельство; этот выпуск делает доступными именно девять
нотных задач, не все возможные уровни музыкального анализа.
