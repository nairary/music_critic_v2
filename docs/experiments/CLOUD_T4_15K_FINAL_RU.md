**Обучение штатно завершило 15 000 обновлений и 30 000 draws.** Остановить его
после 10k через SSH не удалось; пользователь предпочёл дождаться восстановления

## Следующий шаг

Длинное обучение C3 пока отложено. Принятый на CPU runtime `add7eea`
требует отдельного допуска в облаке: до 6 memory forward/backward без обновлений,
32-update equivalence/resume gate, затем парный benchmark исходного и prepared
runtime — 100 warmup + 500 измеряемых шагов на вариант, 4 workers в обоих.
Перед запуском нужны source freeze, planned records и проверенный ограниченный
controller с экспортом и остановкой. Новая VM и новый GPU-прогон при импорте
не запускались. Выигрыш ускорения ещё не измерен.
