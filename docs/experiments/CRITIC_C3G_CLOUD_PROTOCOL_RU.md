Генерация использует существующие проверяемые операторы harmony/rhythm/melody/

генератора, не экспертная разметка мелодии/баса и не обязательный вход модели.

области есть перекрытия или grace-ноты назначенной партии. Arrangement остаётся диагностическим.
Слабый порядок «оригинал выше варианта» действует только для указанного аспекта.
Локальные метки относятся к фактическому вмешательству, не к музыкальной ошибке.

## Допуск, обучение и расходы

Последовательность: завершённая CPU-подготовка → отдельно зарегистрированный

checkpoint, конечные multilevel features, неизменность энкодера, CUDA-обновления,
continuation и время/память. На основании измерения для запущенного
`EXP-CRITIC-C3G-TRAIN-001` выбран предел 6000 применённых обновлений; скорость
старого энкодера для этой оценки не использовалась.

Локальная объединённая проверка завершилась: **378 passed, 1 warning, 20.81 s**.

`c58716fdf5d0243fa3fb568869ac0c0c270aa42b08bdb661ebe51f9b12132fa0`;

`outputs/critic_c3g_20260922/deployment/receipt.json`. Развёртывание проверило
исходники и данные по manifest. Native среда: Torch 2.8.0+cu126, PyG 2.7.0, T4.
`EXP-CRITIC-C3G-GATE-001` имеет статус `completed`, terminal receipt проверен.

модели; затем реальный C3 был загружен и построен полный кеш признаков.

градиентов. Singleton/batch допуск — `rtol=1e-5, atol=1e-5`; continuation —

## Сохранение артефактов

Необязательное копирование source/data/config в Object Storage было отклонено
автоматической проверкой до исполнения из-за отсутствия явного разрешения на
выбранное назначение. Внешний экспорт полностью исключён из текущего запуска.
Это не мешает разрешённой основной кампании и не требует нового запроса
разрешения пользователю.

Checkpoints, кеш и полные логи остаются на существующем диске VM с
`auto_delete=false`; компактные receipts сохраняются локально. Helper
`outputs/critic_c3g_20260922/run_cloud_disk_retained.py` вызывает существующий
supervisor с локальным retainer: он записывает manifest файлов, SHA256, размеры
и receipt сохранения на диске без внешнего назначения. Остановка VM сохраняет
этот диск. Действующий budget guard и абсолютные deadlines не меняются.

Один запуск не доказывает превосходство архитектуры, человеческие предпочтения,
качество полной музыкальной формы или достоверную локализацию ошибок. CHANGES,
PLL, разморозка энкодера, TEST и дополнительные платные модели сюда не входят.
Legacy не использовался. Совместимость API scoring/inference подтверждена,
но готовый inference-артефакт для пользовательского MIDI ещё не выпущен: после
обучения нужно собрать bundle выбранного checkpoint и привязанный к нему
TRAIN reference bank. До этого нельзя представлять API как готовую обученную
систему оценки пользовательского MIDI.
