## Что работает в новом запуске

- Четыре CPU-воркера готовят батчи заранее в подтверждённом порядке sampler.
  Каждый имеет ограниченный кеш2GiB исходных графов; всего8GiB. Кеш
  заполняется по мере обучения, без предварительной генерации12копий каждого
  произведения. Пять незавершённых заданий имеют отдельные ограничения
  сериализованных payload; это не общий предел RAM.
- Checkpoint каждые1000обновлений сохраняет веса, optimizer, scheduler,
  scaler, RNG, sampler, историю и состояние отложенной validation.
  Validation каждые5000обновлений, отдельно на общем с историческим C2
  покрытии и на расширенном. Выбор лучшей модели — по общему покрытию.
- При resume в отдельную папку требуется сохранить ссылку на best из
  родительской попытки: checkpoint сохраняет его score/update, а путь/SHA
  лучшего файла находится в артефактах попытки.
- Отдельный supervisor переживает закрытие SSH. Он проверяет ресурсы
  каждые5с без LLM-проверок, завершает только свою группу процессов,
  автоматически фиксирует терминальный результат и хеши артефактов.
  Пределы:36ч, GPU16GiB, свободная RAM не ниже8GiB, рост swap не более256MiB.
  SIGTERM даёт тренеру30с завершить шаг и сохранить состояние; при аварии
  машины восстановление идёт из последнего сохранённого checkpoint.
