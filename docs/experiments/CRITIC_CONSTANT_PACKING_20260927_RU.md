# Исправление исполнения критика: константы вместо пакетных learned операций

27 сентября 2026. Phase 12 bounded on 9E. Архитектура и протокол обучения
не меняются; legacy не использован. Текущий TRAIN-001 продолжает source004.

## Что не прошло раньше

GATE-004 проверял source005: независимые Linear/GELU и сообщения объединялись
в матричные вызовы. Математические зависимости и порядок связей сохранялись,
но менялся порядок FP32 вычислений и накопления градиентов. На одной TRAIN-паре
максимальное отличие выхода до шага составило 9.80e-5; после AdamW — 6.39e-4.
Различались 45 тензоров весов вне четырёх shared-softmax scalar biases.
Максимальное отличие градиента было 3.04e-7, весов — 3.48e-4. Малое отличие
градиента не гарантирует столь же малого отличия обновления AdamW, особенно
около нуля при eps=1e-8. Графовый аудит не выявил неправильной связи или
перестановки зависимых операций; это численный отказ прежней оптимизации,
а не установленное ухудшение музыкального качества. Source005 остаётся отклонён.

## Исправление source006

В `src/music_critic/critic/device_geometry.py` геометрические индексы, timing,
полные dense weights и скаляры pooling собираются до learned операций.
`model.py` использует их views вместо тысяч мелких materialization вызовов.
Порядок и размеры Linear/GELU, GRU, pooling reductions и fusion сохранены.
Константы живут один forward; module/checkpoint не хранит новый GPU cache.

`tests/critic/test_device_geometry.py` проверяет exact forward/backward/AdamW,
FP32/64, width 8/128, одинаковые и почти одинаковые пары, формы и strides learned
вызовов, неизменность входов, пустые пулы и повторные индексы. Spec review
выявил слишком малую границу pool count для перекрывающихся beat/onset;
два regression-теста сначала упали, после исправления прошли. Финальный
независимый Spec review: без blockers, 15 focused tests passed. Standards
проверены основным агентом: второй независимый агент недоступен из-за лимита.
Полный tests/critic: 350 passed локально (13.65 с), 350 на сервере (18.63 с).

## Native результат

CONSTANTS-GATE-001 завершился failed до загрузки признаков: диагностический
путь не включал подпапку `features`. Ноль forward/optimizer applications;
запись и журналы сохранены. CONSTANTS-GATE-002 — новая попытка, completed.

На RTX3090 / Torch 2.2.2+cu118 проверена прежняя TRAIN-пара Beethoven op13/H1:
два полных представления по 1631 ноте, замороженный неизменяемый feature cache,
fresh seed17, width128, AdamW lr3e-4, clip1, lambda_local0. По одному шагу на
двух независимых копиях. Ни head-dev, ни final holdout, ни TEST не открывались.

|---|---:|

| Loss, градиенты, clip и норма | 0 |

Strict допуски не расширялись; исключения для biases не использовались.
Это точное совпадение на проверенной паре, не доказательство всех будущих
траекторий или допуска полного корпуса.

На общей с TRAIN-001 GPU четыре forward-замера в порядке old/new/new/old
дали 12.391 / 3.730 / 3.799 / 11.286 с на пару. Средние 11.839 и 3.765 с
(отношение 3.14). В отдельном сравнении forward+backward: 18.860 и 11.994 с
(1.57). Backward почти не изменился: 8.384 и 8.282 с. Это короткий диагностический
замер с конкурирующим процессом; переносить коэффициенты на всё обучение
нельзя. PyTorch сообщил о compaction GRU weights в copied comparison; ABBA
использовал отдельно созданные модели. Диагностика заняла 76.96 с по supervisor,
максимум allocated CUDA memory 294682112 байт; wall time не равен GPU busy time.
