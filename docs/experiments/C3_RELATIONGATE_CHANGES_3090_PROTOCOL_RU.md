# C3 relationgate + changes: совместное обучение с нуля

Дата: 2026-09-19. Статус: код и цели подготовлены; native GPU-допуск и
обучение ещё не выполнялись. SSH к 3090 трижды завершился тайм-аутом до
авторизации. Это не результат обучения и не подтверждение GPU-готовности.

Пользователь выбрал обучение с нуля: проверить, может ли один backbone
совместно освоить прежние задачи и дополнительные гармонические модификаторы.
Дообучение от checkpoint и дополнительный контрольный запуск не входят в задачу.

| Параметр | Зафиксированное значение |
|---|---|
| Backbone | C3: три прохода ширины 128, внимание внутри отношений и выбор типа сообщения |
| Задачи | прежние 18 + multilabel-голова на 99 атомов `changes` |
| Инициализация | с нуля; seed 17, dropout seed 17001, changes head seed 17019 |
| TRAIN / VALIDATION | 1 295 / 162 произведения; TEST закрыт |
| Доступные changes | 1 011 TRAIN / 130 VALIDATION; отсутствующие цели маскированы |
| Бюджет | 80 000 optimizer updates, 160 000 draws |
| Батч / воркеры | 2 / 4; очередь до 5 jobs |
| Runtime | FP32, `coalesced_reference`, `pipeline4` |
| Кэш | 8 GiB суммарно для графов; дополнительно до 256 MiB changes на worker |
| LR | исторический горизонт 120k, warmup 6k; остановка на 80k |
| Validation / checkpoint | каждые 5 000 / 1 000 updates |
| Лимит времени | TRAIN до 70 ч; ограничивает процесс, сервер не выключает |

Новая голова читает временные представления backbone. Входы графа остаются
raw-only: `changes` — только цели. На размеченном батче loss равен
`(old18_loss + 0.25 * changes_loss) / 1.25`; без доступных целей — `old18_loss`.
Таким образом, вес старой группы на размеченном батче также меняется. Этот
единственный запуск не отделяет пользу новых целей от эффекта взвешивания.

Подготовленный пакет переносит проверенные sidecars без изменения их байтов.
Порядок 99 атомов и SHA-256 manifest входят в конфигурацию и checkpoint.
Join выполняется по аутентифицированному identity-графу на CPU; далее цели
связываются с фактически преобразованным графом. Сохраняется историческая
транспозиция C2, включая track summaries; её исправление — отдельная абляция.
В этой задаче не меняется PC-set-разметка.

## Допуск и запуск

Последовательность: native CPU-тесты в существующем окружении → максимум
шесть TRAIN forward/backward без optimizer updates → gate из 32 updates /
64 draws со всеми 12 сдвигами и точным resume → отдельное обучение с нуля.
Gate содержит размеченный DLC и AN без changes; memory screen обязан получить
ненулевой градиент новой головы. Ни один из этих GPU-этапов пока не выполнен.

Supervisor сохраняет отчёты и terminal record каждого этапа перед следующим.
Ограничения: выделенный UUID GPU, 16 GiB VRAM на процесс, не менее 8 GiB
свободной RAM, рост swap не более 256 MiB. Ошибка допуска блокирует TRAIN.
Защитная остановка завершает принадлежащие запуску процессы, а не сервер.
Повтор после неудачного этапа получает новый attempt ID.

Плановые записи: `EXP-3090-C3-RELATIONGATE-CHANGES-{PREPARE,MEMORY,GATE,80K}-001`.
Подготовка наследует проверенные `EXP-CHANGES-TEMPORAL-PREPARE-001` и
`EXP-CHANGES-TEMPORAL-ULTRA-AUDIT-001`. Исходный C3: commit
`6e90163444a528154b38e1813f35e345b5668747`; реализация изолирована в ветке
`codex/c3-relationgate-changes-3090-20260919`.

Предназначенный каталог сервера:

Пакет и текущие инструкции на Mac:
`outputs/c3_relationgate_changes_3090_20260919/`.
Точка входа: `python -m scripts.run_changes_3090 --config <sequence.json>`.
Фактический UUID GPU, совместимость native-окружения, наличие исходных файлов,
ресурсы и detached-запуск должны быть проверены после восстановления SSH.

## Что оценивать

Выбор checkpoint сохраняет прежний `primary_score`: средний macro-F1 восьми
основных голов. Дополнительно сохраняются все 18 голов и независимые метрики
changes: per-class precision/recall/F1, micro/macro по поддержанным классам,
варианты с весом исходной аннотации, exact-set на положительных целях.
Пустые и отсутствующие цели различаются. Порог 0.5 фиксирован до обучения.

Сравнение с облачной моделью B4 остаётся описательным: здесь B2 и другая
совокупная функция потерь. Один seed не устанавливает статистическую значимость.
Новые цели обозначают модификации аккорда; они не являются экспертной разметкой
подготовки, задержания, разрешения или голосоведения отдельных нот.
Текущие облачные эксперименты этим запуском не изменяются.

Локальная итоговая проверка: **474 passed, 1 существующее предупреждение PyG,
79.75 s**. Это CPU/synthetic-проверки механики, не оценка качества или скорости
на 3090. Первичная сборка тестов выявила пропущенный audit-script; зависимость
перенесена из проверенного changes checkout, повторный полный набор прошёл.
